# 矫正生存 v1 — PRD

> 产品经理：许清楚
> 版本：v1（从零设计，与 v1/v2 精神矫正中心完全不同）
> 基于用户游戏设计文档，结合 `TowDownGame` 现有代码资产分析产出

---

## 1. 产品目标

**《矫正生存》** 是一款 Top-Down 2D 生存恐怖游戏。玩家从一间封闭房间醒来，需要在扭曲的"矫正机构"中通过潜行、搜刮、解谜和战斗，逐步解锁区域、提升能力，最终面对机构深处的真相。

---

## 2. 用户故事

| # | 用户故事 |
|---|---------|
| US1 | 作为玩家，我希望开局醒来时面临**开门 vs 不开门**的紧迫选择，从而快速代入紧张氛围。 |
| US2 | 作为玩家，我希望在走廊中利用**潜行躲避巡逻敌人**，而不是无脑正面冲突，从而感受到生存压力。 |
| US3 | 作为玩家，我希望通过**搜刮物资和击败敌人获得升级**，渐进式解锁新区域和更长的探索时间。 |
| US4 | 作为玩家，我希望遇到**小 Boss 和封锁节点**迫使我改变路线、动脑思考，从而增加策略性。 |
| US5 | 作为玩家，我希望通过**解谜和发现捷径**获得探索奖励感，并在最终 Boss 战中体验**叙事高潮**。 |

## 3. 六阶段需求池

### 阶段 1 — 房间醒来（核心钩子）

| 优先级 | 需求 ID | 描述 | 备注 |
|--------|---------|------|------|
| **P0** | 1-01 | **敲门触发机制**：玩家在房间内自由移动约 3-5 秒后，触发敲门音效 + UI提示"有人敲门" | 不可跳过，强制引导 |
| **P0** | 1-02 | **开门/不开门选择**：按 E 开门 / 持续等待不开门。开门后护士进入；不开门则进入倒计时 | 需要新增 DoorInteraction 系统 |
| **P0** | 1-03 | **护士进入 AI（开门线）**：护士进入后，启动 **3 秒倒计时**——玩家需要在此期间**背对护士 + 靠墙 + 静止 1 秒**才能避免被攻击 | 新增状态检测逻辑 |
| **P0** | 1-04 | **护士攻击模式（开门线）**：3 秒窗口过后/玩家未完成静默条件，护士立即攻击。攻击力设定为 2-3 点伤害（初始血量 5，风险极高） | 复用 BaseMonster，扩展行为 |
| **P0** | 1-05 | **护士破门（不开门线）**：持续等待约 10 秒后，护士强行破门进入房间并直接攻击玩家 | 破门动画 + 音效 |
| **P0** | 1-06 | **存活条件与过渡**：无论开门线还是不开门线，玩家存活后房间门解锁（或自动打开），通往走廊 | 存活检查 → 走廊场景加载 |
| **P1** | 1-07 | **房间初始搜刮**：房间内放置少量基础物资（绷带 ×1、初始近战武器），鼓励探索 | 复用 BaseLoot |
| **P1** | 1-08 | **护士死亡判定**：在存活阶段如有武器，玩家可以反击护士，但护士有较高的 HP（如 5-8）和短时无敌帧 | 可在参数层面做"前期几乎不可击杀"感受 |
| **P2** | 1-09 | **氛围铺垫**：房间环境色调偏黄/暗，心跳声 bgm，开门瞬间灯光闪动 | 复用 AtmosphereController / SanityServer |

### 阶段 2 — 走廊潜行（核心玩法引入）

| 优先级 | 需求 ID | 描述 | 备注 |
|--------|---------|------|------|
| **P0** | 2-01 | **监护巡逻 AI**：走廊中有 1-2 名"监护"（Orderly）按固定路径巡逻，拥有**视觉锥检测**（前方扇形）和**听觉检测**（脚步声半径） | 新 AI 系统，继承 BaseMonster |
| **P0** | 2-02 | **视野检测系统**：监护视野内发现玩家 → 警觉条上升 → 满后追击并攻击 | 新增 ViewCone2D 组件 |
| **P0** | 2-03 | **听觉检测系统**：玩家跑步（shift）产生脚步声，在监护听觉半径内触发警觉 | 修改 Hero.gd，增加移动噪音值 |
| **P0** | 2-04 | **初级装备限制**：玩家开局仅拥有**耐久度有限的近战武器**（耐久 30-50），最多击杀 2-3 个监护后武器损坏 | 复用 BaseMeleeWeapon，调整参数 |
| **P0** | 2-05 | **生存资源 HUD**：显示血量、体力（冲刺条）、武器耐久、当前警觉度 | 新增 UI 组件 |
| **P1** | 2-06 | **体力系统**：冲刺消耗体力条，体力归零时无法冲刺；站立不动缓慢恢复 | 新增 StaminaServer |
| **P1** | 2-07 | **搜刮基础物资**：走廊各处放置补给品（食物回血、胶带修耐久、钥匙/门禁卡） | 复用 BaseLoot + LootServer |
| **P1** | 2-08 | **掩体/遮蔽**：走廊中有柜子、桌子和拐角，玩家可蹲伏(crouch)减小检测范围 | 新增 Crouch 状态 |
| **P2** | 2-09 | **搜刮与风险权衡**：物资放在尸体旁/死胡同里，高风险高回报 | 关卡设计层面 |

### 阶段 3 — 搜刮升级（成长循环）

| 优先级 | 需求 ID | 描述 | 备注 |
|--------|---------|------|------|
| **P0** | 3-01 | **资源→升级循环**：搜刮到的"强化芯片/医疗记录"等可以提升血量上限、移速、攻击力、体力上限 | 扩展 PlayerData |
| **P0** | 3-02 | **关键道具解锁新区域**：特定道具（如"主任门禁卡"）开启通往下一区域的门 | 新增 Gate/Door 解锁系统 |
| **P0** | 3-03 | **时间+探索范围扩展**：升级后体力/血量提高，可持续探索更长时间、进入更高风险区域 | 依赖 3-01 和关卡设计 |
| **P1** | 3-04 | **武器升级/替换**：可搜刮到更好的近战武器（铁管→消防斧→电击棒），或给当前武器加装改造件 | 复用 + 扩展 BaseMeleeWeapon |
| **P1** | 3-05 | **消耗品系统**：绷带（回血）、止痛药（临时减伤）、咖啡（体力恢复加速）、胶带（修武器） | 新 Consumable 系统 |
| **P1** | 3-06 | **战利品背包管理**：背包只有 8-12 格，玩家需要在"带更多补给"和"带关键道具"之间做取舍 | 复用 LootServer (max_loot_slots) |
| **P2** | 3-07 | **能力树/天赋**：简单的能力树，玩家升级获得天赋点，可选择加强潜行/战斗/生存分支 | 新增 AbilityTree 系统 |

### 阶段 4 — 小 Boss + 封锁节点（压力峰值）

| 优先级 | 需求 ID | 描述 | 备注 |
|--------|---------|------|------|
| **P0** | 4-01 | **小 Boss 触发条件**：到达特定区域（如"医务室""档案室"）触发小 Boss 战 | 新 BossMonster 子类 |
| **P0** | 4-02 | **小 Boss 行为设计**：比普通监护 HP 更高（15-25）、有 1-2 个技能（冲锋、范围攻击、召唤小怪） | 继承 BaseMonster，扩展技能系统 |
| **P0** | 4-03 | **暂时不可通过节点**：某些门被电子锁/需特殊道具/需要从另一边开启，迫使玩家绕路 | 新增 BlockNode 系统 |
| **P1** | 4-04 | **小 Boss 死亡收益**：击败后掉落关键道具（区域钥匙、武器升级件、大量资源） | 复用 BaseLoot |
| **P1** | 4-05 | **路线分支**：遇到封锁节点后，至少有 2 条可探索路线（一条更危险但回报高，一条安全但绕路） | 关卡设计 + 分支判断 |

```

LootServer.gd   — 背包管理、12 格上限、战利品提取
EventBus.gd     — 跨场景事件信号
PlayerData.gd   — 玩家血量/等级/经验框架
AtmosphereController.gd — 环境色调调整（可改为警觉度视觉反馈）
```

```
SanityServer.gd  → 改为 AlertServer.gd（状态名改为警觉度水平而非理智层级）

Hero.gd          → 新增 crouch 状态、移动噪音值
```

```
提取 Extraction 系统 — 本作是线性生存而非撤离射击
```
