# 游戏选择界面 — 实现说明书

## 一、概述

基于 `scenes/learn_main.tscn` 重构，实现了一个全屏适配、垂直滚动的游戏选择界面。列表包含 30 个小游戏条目，每行显示编号、名称及 PLAY 按钮，点击 PLAY 加载对应场景。界面底部提供"返回主菜单"按钮，切换到项目主场景（由 `application/run/main_scene` 配置）。

---

## 二、文件清单

| 文件 | 类型 | 作用 |
|------|------|------|
| `scenes/learn_main.tscn` | 场景 | 游戏选择界面主场景 |

## 五、核心代码解析

### 5.1 GameItem 条目模板（game_item.gd）

```gdscript
extends HBoxContainer

signal game_pressed(scene_path: String)

var scene_path: String = ""

func setup(index: int, game_name: String, path: String) -> void:
    scene_path = path
    $LabelNumber.text = "#%02d" % index
    $LabelTitle.text = game_name
    $ButtonPlay.disabled = path.is_empty()

func _on_play_button_pressed() -> void:
    game_pressed.emit(scene_path)
```

**设计要点：**
- 继承 `HBoxContainer`，作为独立模板被动态实例化。
- `setup()` 接收外部参数，将数据注入子节点，做到数据与展示分离。
- `game_pressed` 信号携带 `scene_path`，父级只需连接信号即可获知要加载哪个场景。
- 空路径（`""`）会触发按钮禁用，防止用户误点。父级的 `_on_game_pressed` 仍作为兜底处理。

### 5.2 主菜单逻辑（game_select_menu.gd）

#### 5.2.1 游戏数据定义

```gdscript
const GAME_LIST: Array[Dictionary] = [
    {name = "GYM 01 - 玩家移动",   path = "res://demo/GYM_01_Movement.tscn"},
    {name = "GYM 02 - 武器射击",   path = "res://demo/GYM_02_Weapon.tscn"},
    # ... 共 30 项
    {name = "小游戏 30 - 暂无",     path = ""},
]
```

- 使用 `Array[Dictionary]` 存储，`name` 为显示文本，`path` 为场景路径。
- 前 17 项映射已有 GYM 场景；后 13 项为占位，`path = ""` 表示暂未实现。
- 新增游戏只需在此数组中追加一行即可，无需修改任何 UI 代码。

#### 5.2.2 动态生成列表

```gdscript
func _populate_game_list() -> void:
    var container := $VBoxContainer/ScrollContainer/VBoxContainer as VBoxContainer
    if container == null:
        push_error("GameSelectMenu: 未找到游戏列表容器节点")
        return

    # 清除编辑器中预设的占位项
    for child in container.get_children():
        child.queue_free()

    for i: int in GAME_LIST.size():
        var data: Dictionary = GAME_LIST[i]
        var item := GameItemScene.instantiate()
        item.setup(i + 1, data.name, data.path)
        item.game_pressed.connect(_on_game_pressed)
        container.add_child(item)
```

**执行流程：**
1. 定位内层 `VBoxContainer`（`ScrollContainer/VBoxContainer`），若不存在则输出错误并返回。
2. `queue_free()` 清空编辑器中可能残留的占位节点。
3. 遍历 `GAME_LIST`，对每项执行：
   - `instantiate()` 克隆模板场景
   - `setup()` 传入编号（从 1 开始）、名称、路径
   - `connect()` 绑定 `game_pressed` 信号到 `_on_game_pressed`
   - `add_child()` 插入到滚动列表中

#### 5.2.3 场景切换

```gdscript
func _on_game_pressed(scene_path: String) -> void:
    if scene_path.is_empty():
        push_warning("GameSelectMenu: 该游戏暂无场景路径")
        return
    var err := get_tree().change_scene_to_file(scene_path)
    if err != OK:
        push_error("GameSelectMenu: 加载场景失败 - %s" % scene_path)

func _on_back_pressed() -> void:
    # 返回项目主场景
    var main_scene: String = ProjectSettings.get_setting("application/run/main_scene", "")
    if main_scene.is_empty():
        push_error("GameSelectMenu: 未配置项目主场景")
        return
    get_tree().change_scene_to_file(main_scene)
```

- 空路径保护：输出 `push_warning`，不执行切换。
- `change_scene_to_file()` 返回 `Error` 枚举，非 `OK` 时输出 `push_error`，方便调试。
- 返回按钮读取 `application/run/main_scene` 项目设置，与 `project.godot` 保持一致，避免硬编码路径。

## 六、布局参数说明

### 6.1 根 Control（全屏适配）

| 属性 | 值 | 含义 |
|------|-----|------|
| `layout_mode` | 3 | 锚点模式 |
| `anchors_preset` | 15 | 四边拉伸（全屏） |
| `anchor_right` | 1.0 | 右边界锚定窗口右侧 |
| `anchor_bottom` | 1.0 | 下边界锚定窗口底部 |
| `grow_horizontal` | 2 | 水平双向拉伸 |
| `grow_vertical` | 2 | 垂直双向拉伸 |

窗口缩放时，根 Control 始终覆盖整个窗口。

### 6.2 VBoxContainer（居中容器）

| 属性 | 值 | 含义 |
|------|-----|------|
| `anchors_preset` | 8 | 中心锚定 |
| `anchor_left/right` | 0.5 | 水平居中 |
| `anchor_top/bottom` | 0.5 | 垂直居中 |
| `offset_left` | -280 | 左偏移（中心向左 280） |
| `offset_right` | 280 | 右偏移（中心向右 280） |
| `offset_top` | -300 | 上偏移（中心向上 300） |
| `offset_bottom` | 300 | 下偏移（中心向下 300） |
| `alignment` | 1 | 子元素居中对齐 |

容器固定 560×600 像素，始终位于窗口正中。

### 6.3 ScrollContainer（滚动区）

| 属性 | 值 | 含义 |
|------|-----|------|
| `size_flags_vertical` | 3 | 垂直方向扩展/填充 |
| `horizontal_scroll_mode` | 0 | 禁用水平滚动 |

30 项总高度约 30 × 48 = 1440px，容器高度约 500px，超出自动出现垂直滚动条。

### 6.4 GameItem（条目模板）

| 属性 | 值 | 含义 |
|------|-----|------|
| `custom_minimum_size` | (0, 44) | 最小高度 44px |
| `alignment` | 1 | 子元素垂直居中 |

## 七、如何扩展

### 7.1 添加新游戏

在 `game_select_menu.gd` 的 `GAME_LIST` 数组中插入一行：

```gdscript
{name = "GYM 17 - 新游戏名称", path = "res://demo/GYM_17_NewGame.tscn"},
```

无需修改场景或模板文件。

### 7.2 修改条目样式

编辑 `game_item.tscn`：
- 调整 `LabelSettings` 子资源的 `font_size`、`outline_size`、`outline_color`
- 修改 `ButtonPlay` 的 `custom_minimum_size` 调整按钮宽度
- 修改 `GameItem` 的 `custom_minimum_size` 调整行高

### 7.3 修改标题或返回目标

- 标题文本：修改 `learn_main.tscn` 中 `LabelTitle.text`
- 返回目标：修改 `project.godot` 中 `application/run/main_scene` 设置即可，`_on_back_pressed()` 会自动读取项目主场景
