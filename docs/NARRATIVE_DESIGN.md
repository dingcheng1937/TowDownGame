## 1. 核心叙事框架

### 1.1 中心主题问题

> **游戏问的核心问题是：当每一个"合理决策"都指向同一个方向，谁来为结果负责？**

这个问题没有答案。游戏不提供答案。玩家在废墟中找到的每一份文件都在说：  
每个人都有理由。每个机构都在"为了更好"。  
而这座城市，现在是地狱。

### 1.2 玩家的情感弧线

| 阶段 | 关卡 | 玩家状态 | 叙事信号 |
|------|------|----------|----------|
| 置身其中 | 精神病院 | 困惑、被评判 | "为什么我在这里" |
| 开始怀疑 | 中学/工厂 | 识别模式、不安 | "这些地方有某种联系" |
| 系统认知 | 夹层 | 愤怒、幻灭 | "这本就是同一个东西" |
| 真相逼近 | 地下 | 恐惧、悲悯 | "外神不是原因" |
| 面对终局 | 祭坛 | 麻木中的清醒 | "这一切都被批准过" |

### 1.3 主角设定（玩家角色）

**主角没有名字，没有台词。**

这是刻意的叙事选择：
- 玩家不知道自己为什么在这里——和所有受害者一样
- NPC们用"编号"、"受试者"、"实验对象"称呼主角
- 随着游戏进行，偶尔的NPC会用一个普通的名字喊主角——这让玩家第一次感受到自己是"人"

**主角的叙事功能**：考古学家。他们挖掘废墟，拼凑真相，但无法改变已经发生的事。

## 2. 主题系统

### 2.1 五大机构主题对照

| 机构 | 核心主题 | 权力技术 | 话语武器 | 最终形态 |
|------|----------|----------|----------|----------|
| 圣芙蕾雅精神病院 | 定义何为正常 | 诊断权 | "你生病了" | 灵魂牧场 |
| 明德中学 | 制造优秀样本 | 排名权 | "你不够好" | 合格品流水线 |
| 永安工业区 | 消耗与替换 | 雇用权 | "你是零件" | 人力消耗机器 |
| 海市制药 | 痛苦商品化 | 解释权 | "这是为了治疗" | 苦难提炼厂 |
| 玄真道观 | 超脱与献祭 | 救赎权 | "这是解脱" | 终极消费者 |

**五者共同话语逻辑**：
1. 建立一个关于"应该"的标准
2. 证明你不符合标准
3. 以"帮助"之名消费你的偏差
4. 产出物流入下一个机构

### 2.2 外神的叙事角色

外神**从不出现在画面中**。祂的存在通过以下方式体现：

- **环境畸变**：某些区域的几何结构不合常理——角度不对，空间感扭曲，但不突兀
- **文件中的空白**：最后几页始终缺失，编号跳跃
- **SanityServer**：玩家的理智衰减不是因为外神施压，而是因为玩家越来越清楚地**看见**人类做了什么
- **Boss死亡时刻**：Boss在死前的最后一句话，总是某种形式的"我做的是对的"

外神的存在逻辑：**一座以痛苦为食的城市，终将吸引以城市为食的存在。**

## 3. 角色语音柱石

### 3.1 治疗主任（现有Boss · 圣芙蕾雅精神病院）

```
身份：圣芙蕾雅精神病院主任医师
核心伤：他曾经真的相信自己在帮助别人
欲望：维持秩序，让一切在掌控中运行
需要：有人告诉他他错了——而他从未听见
```

**语音柱石**

- **词汇风格**：医学术语混入日常语言；从不用"惩罚"，只用"干预"；从不用"囚禁"，只用"留观"
- **句式节奏**：长句，多个从句，声音里带着耐心——那种对你解释的耐心，但不期待你真的理解
- **回避话题**：从不谈"失去"，只谈"调整"；从不承认有人"死在"这里
- **语言标记**：习惯说"从临床角度来看"、"这只是短暂的不适"、"你会理解的"
- **潜台词默认值**：他永远不说他真正的意思——他相信自己的措辞本身就是真相

**绝不会说的台词**（附原因）
- ~~"你在受苦。"~~ — 他只说"你的症状表现为……"
- ~~"对不起。"~~ — 没有错误，只有"治疗方案需要调整"
- ~~"出去。"~~ — 病人永远是"准备好了才能离开"

**参考台词（已审定）**

```
"你不需要害怕。恐惧本身就是症状的一部分，我们会处理的。"
— 展示词汇（"症状"代替"感受"）和潜台词（你的恐惧证明了你需要被治疗）

"大多数人在第二周就会好很多。绝大多数。"
— 展示信息回避：那些没好的人去哪里了，他不说

"我见过很多像你这样的案例。你会没事的。"
— 施压下的情感节奏：用"你会没事的"来终止而非回应
```

### 3.2 年级主任（明德中学Boss）

```
身份：明德中学教务主任，执行评级与淘汰制度的人
核心伤：他本人是这套系统筛选出来的"成功者"，从未想过代价
欲望：证明系统是有效的（因为否则他的成功也没有意义）
需要：被允许说一次"这不公平"——他从未被允许
```

**语音柱石**

- **词汇风格**：教育话语，充满"培养"、"潜力"、"未来"——全是对结果的投资，没有对人的关注
- **句式节奏**：斩断式短句，习惯用排比；会突然停顿，像在等你说"是"
- **回避话题**：从不谈失败的学生去了哪里；从不谈排名以外的价值
- **语言标记**："这就是社会的规则"、"你要感谢这段经历"、"落后是你自己的问题"
- **潜台词**：他知道有问题，但承认问题等于否定自己的一生

**绝不会说的台词**
- ~~"这对你不公平。"~~
- ~~"排名不代表你的价值。"~~
- ~~"我也曾经怀疑过这套系统。"~~

**参考台词**

```
"第一名的位置只有一个。这不是残忍，这是真实。"

"你以为我不清楚吗？我比你更清楚。所以我才能站在这里。"
— 施压下暴露：他清楚，他选择不看

"你的成绩说明了一切。如果你想要不同的答案，去取得不同的成绩。"
— 典型封闭式逻辑：用规则本身来回避对规则的质疑
```

### 3.3 厂长（永安工业区Boss）

```
身份：永安工业区负责人，执行"零件化"用工逻辑的人
核心伤：他曾经是工人，他知道那种感觉，这让他的冷漠更有意识
欲望：效率，完成指标，不被追责
需要：被人当人看——他把这个需要彻底压进去了
```

**语音柱石**

- **词汇风格**：数字、产能、损耗率；从不用人名，用工号；情感词汇完全消失
- **句式节奏**：极简，像报表一样；没有多余的词
- **回避话题**：从不谈具体的人；从不谈他自己的过去
- **语言标记**："这是行业惯例"、"合同里写清楚了"、"替换成本比维修低"
- **潜台词**：他的冷漠是一种训练出来的东西，不是天生的

**参考台词**

```
"工伤率在可接受范围内。"

"你要说什么？这里每个人都签了合同。"
— 合同作为免责机制：签了字就与他无关了

"（停顿）换个人来。"
— 在他的认知系统里，这是合理回应——不是残忍，是效率
```

### 3.4 首席研究员（海市制药Boss）

```
身份：海市制药核心研发负责人
核心伤：他从科学出发，真的相信可以量化痛苦，真的相信这有意义
欲望：突破——解码苦难的本质，找到可复制的公式
需要：有人问他"但那是人"，而不是"但那是样本"
```

**语音柱石**

- **词汇风格**：科学语言极度精确；情感词被替换为神经科学术语；谈论人类像谈论化合物
- **句式节奏**：思考中的人，常有停顿；句子有时是自言自语；会修正自己的用词
- **回避话题**：从不说"死亡"，只说"实验终止"；从不谈受试者的名字
- **语言标记**："从数据角度"、"这不是残忍，这是必要性"、"你无法理解这个工作的重要性"

**参考台词**

```
"痛苦是可以被测量的。一旦可以被测量，就可以被利用。这不是坏事——这是进步。"

"3号样本的应激反应数据非常有价值。我很遗憾实验无法继续。"
— "遗憾"指向的是数据，不是生命

"你问我良心？良心是一种认知偏差。我不允许它干扰研究精度。"
```

### 3.5 观主（玄真道观Boss）

```
身份：玄真道观当代道主，是这套系统中唯一"自愿"者——而这让他最危险
核心伤：他真的痛苦过，真的在某种意义上"超脱"了，但超脱的方式是把痛苦转移出去
欲望：世界秩序的更新，以献祭为代价换取虚无的平静
需要：有人陪他一起承认：某些痛苦没有意义，就是没有意义
```

**语音柱石**

- **词汇风格**：古语和现代语混用；说话像在念经，但内容其实很具体；用平静的语气说极端的话
- **句式节奏**：长，慢，像水流；会在句中停顿，等某种节奏
- **回避话题**：从不谈他送走了多少人；从不用"牺牲"，只用"归宿"
- **语言标记**："世人皆苦"、"这是解脱"、"你只是还不明白"

**参考台词**

```
"来这里的人，都是世界不需要的。我们给他们一个归宿。你说这残忍吗？"

"（平静）我送走了很多人。他们走时都很安静。"
— 他把这当做慈悲——这是最深的恐怖

"你觉得你会活着离开？（停顿）这不是威胁。这是预言。"
```

### 3.6 市长/大祭司（终局Boss）

```
身份：这座城市行政最高负责人，五机构体系的"顶层设计者"
核心伤：他是所有人中最难界定"恶意"的——他真的相信他在建设
欲望：城市的秩序与发展，从未想过为此付出的代价是人
需要：没有。他从未允许自己有需要。这才是问题所在。
```

**语音柱石**

- **词汇风格**：政府话语；宏大叙事；用城市、人民、未来说话，从不用具体的人
- **句式节奏**：演讲腔，但在私下场合会崩塌；会突然变得非常简短，几乎像孩子
- **回避话题**：个体，细节，具体的名字
- **最终时刻语言**：演讲腔崩塌，他说出某个具体的名字——可能是他已经忘记的某个人的名字——然后停止

**参考台词（终局）**

```
"这座城市里的每一个决定，都经过了委员会的审议。
每一份文件都有签名。每一次投票都是合法的。
（转向玩家）所以告诉我——是谁的错？"

"（崩塌后）……朱明辉。32号。
（停顿）
我不记得他了。我应该记得的。"
— "朱明辉"是第一个进入医院-学校-工厂系统的编号记录者。他的名字出现在Tier 3文件中。
— 市长在临死前突然想起他，这是他最接近人性的时刻，也是最后时刻。
```

### 4.2 理智系统对话触发器

当 `SanityServer` 中理智值降至特定阈值，触发环境对话（非NPC，是空间说话）：

| 理智阈值 | 触发文本 | 呈现方式 |
|---------|----------|----------|
| 80% | 隐约听见广播：「第……号，请到……室……」 | 淡入字幕，声音扭曲 |
| 60% | 墙上的文件开始显示名字（随机生成的名字） | 屏幕边缘叠加 |
| 40% | 听见主任的声音：「你的配合度……」 | 空间残响，无定位 |
| 20% | 听见一个孩子说话：「今天公布排名了。」 | 清晰，像在身边 |
| 5% | 完全的静默 | 所有环境音消失 |

## 5. 各区域叙事设计

### 5.1 圣芙蕾雅精神病院

**区域叙事功能**：让玩家体验"被诊断"，而非"被伤害"。暴力是隐形的。

**入场叙事节拍**：
1. 玩家从一张病床上醒来——没有说明这是为什么
2. 床头有一份"入院记录"：姓名处是编号，病因处是空白，主治医师：陈宏仁（治疗主任）
3. 走廊里护士正常巡逻，不觉得有任何异常
4. 第一个被锁住的门——门上有审批签字，日期正常，流程正确

**Boss战叙事意义**：
击败治疗主任不是一场"正义的胜利"。他死前说的那句"我只是想……治好他们"让这场胜利充满不适感。  
玩家拿到的钥匙卡，上面写着：`主任授权 · 紧急撤离通道`。  
他生前准备了这张卡——为了某个他想救的人，或者为了某种他从未触碰到的善意。

---

### 5.2 明德中学

**区域叙事功能**：让玩家看见孩子是如何被系统加工的，以及加工者自身也是产品。

**关键发现节拍**：
- 黑板上最后一次写的排名，还没被擦掉
- 最后三名的名字，出现在精神病院的入院名单上
- 一份"优秀毕业生追踪档案"，全部流向了永安工业区

**Boss战后发现**：
年级主任的办公室抽屉里，有一张他自己的小学成绩单。排名：42名（共43人）。  
这份文件没有任何注释。玩家自己理解。

---

### 5.3 永安工业区

**区域叙事功能**：让抽象的"消耗"变成可见的数字。

**关键发现节拍**：
- 每条流水线边都有"本月工伤记录"，格式极度标准化
- 某个工位的工伤记录右侧有手写的小字："他有两个孩子"——然后被划掉了，下面写着"已记录，无需附注"
- 失踪工人名单 vs 玄真道观祭祀记录：日期吻合

**区域特殊机制**：
这个区域有传送带机制——玩家会被传送带带走，必须主动抵抗。  
这是叙事-gameplay整合的关键点：**你感受到的被迫移动，就是这里每个工人每天的感受。**

---

### 5.4 海市制药

**区域叙事功能**：让"科学"成为暴力的语言。

**关键发现**：
- 样本库中有编号，某些编号和精神病院的病历编号完全一致
- 一份内部备忘录：`关于样本质量保障与来源稳定性的讨论纪要`
  - 第三条："建议与教育部门和工业区建立长期合作，确保高应激反应个体的持续供应"
  - 审批人：[市长签名]
  - 日期：三十七年前

**这份备忘录是Tier 2文件，但其中市长签名在Tier 3文件中被反复验证**——玩家在不同层级发现真相的不同碎片。

---

### 5.5 玄真道观

**区域叙事功能**：让"救赎话语"成为系统的最终承接者。

**区域氛围设计**：
这是游戏中第一个**看起来温暖**的地方。香火，木质，低光，安静。  
然后玩家注意到：香炉的香，气味不正常。  
然后玩家注意到：祈福牌上的名字，和其他地方的失踪名单重合。  
然后玩家注意到：地下神龛进去之前，有一份"接收登记表"。

**观主登场前的独白**（玩家进入核心区域时，从广播系统播放的录音）：
```
"世间苦，苦在执着。
执着于身份，执着于名次，执着于产出。
来这里的人，都放下了。
（停顿）
他们被帮助着，放下了。
（更长的停顿）
这不是结束。这是……
（录音在这里中断，有轻微的杂音，像是有人关掉了录音机）"
```
录音在"这是"之后中断——观主自己也没法说出他要说的那个词。

### 5.6 中央枢纽站（叙事核爆点）

这是游戏中最重要的叙事节点。

**玩家在这里必须看见的东西**：
一张地下通道连接图，贴在值班室的墙上。  
图上标注着所有机构的地下出入口，连接关系，以及每条通道的"用途备注"。  
通道用途写得很官方，很正常，全部盖有审批章。

**玩家第一次完整地看见这个系统是一个整体。**

这个时刻不需要任何台词。只需要这张图，和图上的审批章。

## 7. 环境叙事提案

### 7.1 圣芙蕾雅 · 病房303

**这里发生了什么**：
303的住客是一位前市政规划局工程师。他发现了地下通道设计图中的异常，试图举报，被以"职业压力引发的偏执型障碍"为由入院。他在这间病房住了四年。

**玩家应该推断出**：不是所有病人都生病了。诊断是一种行政工具。

**刻意留白**：这位工程师最后去了哪里，没有答案。

**道具放置**：
- 床头：摆放整齐的折纸（极度规整，说明他用大量时间来保持秩序感，这是被关闭的人维持理智的方式）
- 床边地板：一排折纸动物，摆成了某种图案——玩家仔细看会发现，那是一张简化的地下通道图
- 墙上：用钥匙划出的划痕，记录天数，数到第1461天（四年），然后停止
- 书桌：一本从图书馆借出的建筑学书籍，某几页被反复翻阅，用于确认他的记忆是否正确

**光线叙事**：窗户是毛玻璃，光线进来但看不见外面。温和，安全，封闭。

**声音叙事**：偶尔的广播声从走廊渗进来，音量刚好让你听见"……号……室……"，听不完整。

**层级**：Tier 2（玩家需要进入并仔细查看）

---

### 7.2 明德中学 · 教师办公室

**这里发生了什么**：
这是一个老教师的工位。她教书三十年。她见过这套系统把多少孩子送进黑洞，但她找不到出口。最后，她自己也被系统"安排"了退休。

**玩家应该推断出**：体制内的人不是不知道，是知道了也无法改变。

**道具放置**：
- 抽屉里：一个信封，装着三十年前她最喜欢的学生的来信，其中一封写"老师，我已经到工厂了，还好"
- 桌面：用红笔批改到一半的卷子，红笔还夹在卷子上
- 墙上的奖状：三十年间的"优秀教师"证书——越往后，越没有她自己写的任何东西，只是格式化的表彰

**刻意留白**：她最后是怎么"安排退休"的，没有说。

**层级**：Tier 2

---

### 7.3 市政厅 · 地下会议室

**这里发生了什么**：
三十七年前，这里开了一次会，决定了所有的事。那份会议纪要至今存档。

**玩家应该推断出**：所有的灾难都被投票通过了。

**道具放置**：
- 会议桌：依然整洁，水杯还在，像是中途休会
- 每个座位前：名牌，官职头衔，一个审批章
- 桌面上：那份Tier 3文件（会议纪要），在最显眼的位置
- 长桌尽头的椅子比其他椅子高3厘米——这是市长的位置，没有任何标注，只有高度

**光线叙事**：荧光灯，正常工作状态，没有任何异常。这里唯一诡异的是，它太正常了。

**声音叙事**：无声。绝对无声。这是游戏中唯一完全无声的房间。

**层级**：Tier 1（玩家必须经过这里才能进入最终区域）

| 叙事节拍 | Gameplay机制 | 玩家感受 | 实现建议 |
|---------|-------------|---------|---------|
| 入院——被评定 | SanityServer开始计时 | "我受到了某种看不见的评判" | 入场时SanityServer静默启动 |

## 9. 世界圣典（World Bible）

### 9.1 时间线

| 时间 | 事件 |
|------|------|
| 60年前 | 圣芙蕾雅精神病院建立。起初是真正的医疗机构。 |
| 50年前 | 明德中学建立"综合素质评定体系"。最初是教育改革试点。 |
| 45年前 | 永安工业区扩建，建立对接学校的"优先录用"通道。 |
| 40年前 | 海市制药与圣芙蕾雅签署"临床样本合作协议"。 |
| 37年前 | 秘密会议召开。五机构统一纳入城市"综合效能管理体系"。外神第一次出现在记录中（一条划掉的脚注）。 |
| 30年前 | 地下通道完工。名义上是"城市基础设施"。 |
| 10年前 | 外神"凝视"（记录：城市开始出现无法解释的现象，率先出现在医院）。 |
| 游戏开始前3年 | 城市对外封锁通讯。官方说法：内部整顿。 |
| 游戏开始 | 玩家在病床上醒来。 |

### 9.2 势力关系

| 势力 | 目标 | 对玩家态度 | 内部矛盾 |
|------|------|------------|---------|
| 精神病院 | 维持秩序，消化社会异常 | 需要被治疗的对象 | 部分医护有良知，无法离开 |
| 学校 | 制造合格产品 | 评估对象 | 老教师知道真相，无法改变 |
| 工厂 | 最大化产能 | 零件 | 基层工人知道同事去了哪里 |
| 制药 | 研究进展，数据积累 | 样本 | 研究员对数据着迷，不看数据背后 |
| 道观 | 承接系统无法处理的人 | 归道者 | 低层道众不知道全貌 |
| 市政府 | 城市整体运转 | 行政编号 | 内部极少数人知道，已被消化 |

### 9.3 世界规则

**物质层**：这是一座真实的现代城市，物理定律正常。

**心理层**：SanityServer代表的不是超自然感知，而是玩家越来越清晰地看见真相的过程。理智降低=认知越来越完整。（注：这是反直觉设计——越"清醒"，理智越低，因为清醒本身无法承受。）

**外神层**：外神不是一个形状，不是一张脸，不是一个意图。它是城市自身逻辑的放大器。玩家永远不会看见它，只会看见它让哪些事情变得无法回避。

### 9.4 绝对禁止的改写（Banned Retcons）

这些在Tier 1建立的事实不可在任何后续内容中推翻：

1. 治疗主任临死前说的那句"我只是想……治好他们"——他的善意不可被否定，但善意造成的伤害同样真实
2. 市政会议纪要中的全票通过——不存在某个"幕后真正的黑手"推动这一切，就是集体决策
3. 幸存者（枢纽站NPC）的陈述——关于地下通道的叙述是可靠的
4. 外神是回应者而非入侵者——这一点在Tier 2揭示后，所有后续内容必须一致
