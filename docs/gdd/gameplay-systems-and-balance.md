## 1. 设计支柱

> 每一个设计决策，都可以而且必须被这四根支柱检验。如果某个系统不和其中至少两根支柱对齐，它就是多余的。

### 支柱 A：潜行是默认策略，战斗是最后手段

**玩家感受**：我永远处于劣势。正面冲突是我主动选择的、经过计算的风险，而不是系统强加给我的。

**设计约束**：
- 玩家初始状态无法同时处理 2 个以上敌人
- 每一次开枪/奔跑都产生不可逆的全局成本（警戒值）
- 击杀有限配额（阶段2 N=3），超限触发惩罚
- 80% 的敌人可以在不被发现的情况下绕过

**验证问题**："玩家能否在不被发现的情况下完成阶段2？如果不能，问题出在哪里？"

### 支柱 B：信息是真正的稀缺资源

**玩家感受**：每一次转角都是未知的。我能听见、隐约看见，但永远不完全确定。我必须用投掷物试探、用听觉推断，用足迹规划路线。

**设计约束**：
- 敌人的视野锥是唯一可靠的信息来源 —— 看到锥 = 看到敌人
- 声音提示（脚步声、开门声、敌人巡逻声）是空间音频，不给小地图标记
- Sanity（理智）下降时，部分信息变得不可靠（幻觉脚步声）
- 没有小地图雷达，没有敌人标记

**验证问题**："玩家在进入一个新房间前，有哪些信息源可以做出决策？"

### 支柱 C：每一次搜刮都是一个有代价的选择

**玩家感受**：我看到那个物资了 —— 它在走廊尽头，在一个巡逻路径的交汇处。值不值得去？我的武器耐久只有 12 了，背包还有 2 格空位。

**设计约束**：
- 所有物资都有两种成本：**获取成本**（警戒增加/被发现的概率）和**持有成本**（背包空间）
- 物资没有"纯粹好"的 —— 高价值战利品往往要求玩家放弃其他选择
- 安全屋是唯一的"无代价"空间 —— 且数量有限

**验证问题**："玩家是否曾经站在一个物资面前犹豫了至少 2 秒？"

### 支柱 D：故事通过系统说话

**玩家感受**：我不需要读过场文本就能感受到这个机构的压迫感。约束带的技能是"定身"，主任的台词是"这只是短暂的不适"——系统的行为和叙事文本互相印证。

**设计约束**：
- Boss 的每一个技能必须和叙事中的"权力工具"对应
- 环境叙事触发条件必须是玩家行为驱动的（如：Sanity < 50% 触发幻觉 whisper），而非被动播片
- 每一份可收集文档必须改变玩家对至少一个游戏系统的理解

**验证问题**："如果删掉所有文本，玩家还能通过系统行为理解这个 Boss 是什么人吗？"

## 2. 核心玩法循环

### 2.1 瞬间循环（0–30 秒）
**玩家的认知-行动-反馈周期**

```
    观察 ──→ 决策 ──→ 执行 ──→ 反馈 ──→ 观察
      │                  │
  巡逻路径？          移动/蹲伏/投掷
  视野锥？            等待/冲刺/攻击
  声音来源？          开门/关门/拾取
```

| 阶段 | 玩家行为 | 系统反馈 | 时间窗口 |
|------|----------|----------|----------|
| 观察 | 静止、分析巡逻模式 | 视野锥可见、脚步声空间化 | 3–10s |
| 决策 | 选择路径/时机/是否交战 | 无（系统不催促） | 任意 |
| 执行 | 移动/攻击/使用物品 | 立即物理反馈（动画/音效） | 0.5–3s |
| 反馈 | 确认结果 | AlertServer 变化/物品拾取音效/血量变化 | 即时 |

### 2.2 会话循环（5–30 分钟）
**单次探索的叙事弧线**

```
┌─────────────────────────────────────────────────────────────┐
│  进入区域 ─→ 探索/搜刮 ─→ 遭遇敌人 ─→ 消耗资源 ─→ 找到出口 │
│      │                                    │                │
│      └──── 警戒值攀升 ─→ 更多敌人 ─→ 压力增大 ─┘             │
│                           │                                  │
│                    安全屋(压力释放)                           │
│                    升级(能力增长)                             │
│                    Boss(压力峰值)                             │
└─────────────────────────────────────────────────────────────┘
```

**会话节奏设计**：

| 节拍 | 时长 | 玩家状态 | 系统状态 |
|------|------|----------|----------|
| 探索期 | 3–8 min | 谨慎、好奇 | 警戒 0–30，敌人稀少 |
| 积累期 | 5–10 min | 自信、计算 | 警戒 30–60，敌人增多，背包渐满 |
| 高压期 | 3–8 min | 紧张、资源紧张 | 警戒 60–80，Boss 触发，撤离开始 |
| 终局 | 2–5 min | 爆发或崩溃 | 警戒 80+ 或撤离中 |

### 2.3 长期循环（跨会话）

```
单局探索 → 撤离成功 → 金币入账 → 仓库升级 → 下一局能力增强
     │                      │
     └── 死亡 ──→ 丢失当次背包 → 仓库界面 → 再次尝试
```

**核心长期张力**：
- 每次撤离成功后玩家带着更强能力投入下一局
- 但每次死亡都清零当次背包 —— 高风险高回报的搜刮策略在这里开始有意义

```
                    ┌─────────────┐
                    │   HUD/UI    │ ← 信息呈现层
                    └──────┬──────┘
                           │
    ┌──────────────────────┼──────────────────────┐
    │                      │                      │
    ▼                      ▼                      ▼
┌────────┐          ┌──────────┐          ┌────────────┐
│ 潜行系统 │◄────────►│ 警戒系统  │◄────────►│ 理智系统    │
│ Stealth │  交互    │ Alert    │  交互    │ Sanity     │
└───┬────┘          └────┬─────┘          └─────┬──────┘
    │                    │                      │
    │   ┌────────────────┼──────────────────┐   │
    │   │                │                  │   │
    ▼   ▼                ▼                  ▼   ▼
┌─────────────────────────────────────────────────────┐
│              敌人 AI 行为决策层                        │
│  (巡逻 → 警觉 → 追击 → 攻击 → 呼叫增援)              │
└───────────────────────┬─────────────────────────────┘
                        │
    ┌───────────────────┼───────────────────┐
    ▼                   ▼                   ▼
┌────────┐        ┌──────────┐        ┌──────────┐
│ 战斗系统 │        │ 搜刮系统  │        │ 升级系统  │
│ Combat  │        │ Loot     │        │ LevelUp  │
└───┬────┘        └────┬─────┘        └────┬─────┘
    │                  │                   │
    └──────────────────┼───────────────────┘
                       ▼
              ┌────────────────┐
              │  撤离/死亡结算   │
              │  Extraction     │
              └────────────────┘
```

**系统之间的关键关系**：

- **潜行 → 警戒**：玩家的噪音和可见度直接影响 AlertServer
- **警戒 → 敌人AI**：警戒值越高，敌人搜索范围越大、反应越快
- **理智 → 潜行**：低理智产生幻觉干扰，使玩家更难判断真正的威胁
- **战斗 → 警戒**：每次击杀产生大量噪音，快速推高警戒
- **搜刮 → 升级**：搜刮的物资直接转化为跨局能力
- **撤离 → 搜刮**：只有成功撤离的物资才能保留

## 4. 玩家压力三角

玩家始终在三条压力轴上做权衡：

```
              警戒 (Alert)
              /\
             /  \
            /    \
           /  决策 \
          /  空间  \
         /          \
        /            \
  理智 (Sanity) ──── 生命/体力 (HP/Stamina)
```

### 4.1 警戒轴

**核心设计意图**：警戒是玩家的"熵"——它会持续增长，无法完全消除，只能管理增速。

| 行为 | 警戒变化 | 设计理由 |
|------|----------|----------|
| 步行 | 0/s | 基线，不产生警戒 |
| 蹲伏 | 0/s | 更安全但更慢 |
| 奔跑 | +5/s | `[PLACEHOLDER]` 代价显著但可接受短期使用 |
| 推开杂物/碰撞声响 | +10 瞬时 | 一次性惩罚，鼓励玩家观察物理环境 |
| 投掷石子（引开敌人） | +5 瞬时 | 主动控场工具，可接受的成本 |
| 投掷药瓶（范围效果） | +15 瞬时 | 强力控场，更高成本 |
| 近战击杀 | +15 瞬时 | 高代价，鼓励潜行绕过而非战斗 |
| 枪声 | +25 瞬时 | 极高代价，几乎必然触发警报 |
| 被敌人发现 | +20 瞬时 | 对失误的惩罚 |
| 在安全屋 | -3/s | 唯一的警戒降低手段 |
| 自然衰减（非安全屋） | -0.5/s | 非常缓慢，不足以抵消奔跑成本 |

**警戒阈值效果**：

| 阈值 | 值范围 | 效果 | 玩家感受 |
|------|--------|------|----------|
| NORMAL | 0–29 | 正常巡逻 | "还算安全" |
| WATCHFUL | 30–59 | 敌人数+1，巡逻速度+20%，搜索范围+30% | "他们开始注意了" |
| ALARM | 60–79 | 敌人数+1，无人机激活，所有敌人主动搜索 | "被盯上了" |
| LOCKDOWN | 80–100 | 敌人数+2，撤离点可能被封锁，无敌时间 | "必须走了" |

### 4.2 理智轴

**核心设计意图**：理智不直接杀死玩家，但它使一切变得更难。理智是"信息税"——它让你更难做出正确的决定。

**重要设计说明**：理智在叙事上代表"看穿真相的能力"，在 gameplay 上代表"信息可靠性"。理智下降时，玩家不是变弱，而是变得越来越难以区分真假。

| 理智范围 | 标识 | 视觉效果 | Gameplay效果 |
|----------|------|----------|-------------|
| 75–100 | Normal | 正常色彩 | 正常 |
| 50–74 | Mild | 轻微褪色, contrast=1.1 | 偶尔出现虚假脚步声（15%概率每20秒） |
| 25–49 | Moderate | 明显褪色, contrast=1.2 | 虚假脚步声频率↑、偶尔出现幻觉敌人（不可交互的影子） |
| 0–24 | Severe | 严重扭曲, contrast=1.4 | 虚假敌人频率↑↑、真实敌人视野锥偶尔"闪烁"（不可靠） |
| 0 | Broken | contrast=1.6, 几乎黑白 | 持续幻觉、控制偶尔反向（10%概率，持续0.3s） |

**理智变化来源**：

| 来源 | 变化量 | 触发条件 |
|------|--------|----------|
| 自然流失 | -0.5/s | 始终存在（`[PLACEHOLDER]`） |
| 低语者光环 | -2/s | 在 Whisperer 150px 范围内 |
| 发现文件/真相 | -5 瞬时 | 拾取叙事战利品时（反直觉设计：真相=理智下降） |
| Boss 阶段切换 | -10 瞬时 | 叙事冲击 |
| 安全屋恢复 | +3/s | 在安全屋中 |
| 使用镇静剂 | +25 瞬时 | 消耗品 |

### 4.3 生命/体力轴

| 属性 | 初始值 | 最小值 | 最大值 | 恢复方式 | 耗尽后果 |
|------|--------|--------|--------|----------|----------|
| HP | 5 | 1 | 8 (升级) | 绷带(+2)、安全屋(+1/5s) | 死亡 |
| 体力 | 100 | 0 | 150 (升级) | 静止恢复(+20/s)、咖啡(+50) | 无法冲刺/蹲伏 |
| 武器耐久 | 40 | 0 | 80 (升级) | 胶带(+25) | 无法攻击 |

## 5. 潜行系统平衡

### 5.1 双通道检测模型

```
敌人检测概率 = f(视觉通道, 听觉通道, 距离)

视觉通道:
  visibility = 基础可见度 × 蹲伏系数 × 阴影系数 × 距离衰减
  - 基础可见度: 1.0 (站立)
  - 蹲伏系数: 0.3 (蹲伏时可见度降低70%)
  - 阴影系数: 0.5 (在阴影中时)
  - 距离衰减: 1.0 - (distance / max_vision_range)
  - 阈值: visibility > 0.3 → 可见

听觉通道:
  noise_level = 基础噪音值 + 行为噪音
  - 蹲伏: 0
  - 步行: 5
  - 奔跑: 30
  - 攻击: 40
  - 枪声: 80
  - 听觉半径内 noise_level > 10 → 警觉
```

### 5.2 敌人视觉锥参数

| 敌人类型 | 视觉角度 | 视觉半径 | 反应时间 | 特殊能力 |
|----------|----------|----------|----------|----------|
| PatrolGuard（巡逻员） | 120° | 200px | 1.5s 警觉 | 无 |
| SurveillanceDrone（无人机） | 360° | 300px | 0.5s 警觉 | 全向视觉、不可击杀 |
| SedationEnforcer（镇压者） | 90° | 150px | 2.0s 警觉 | 短程（慢但伤害高） |
| NurseAI（护士） | 140° | 180px | 1.0s 警觉 | 破门能力 |

### 5.3 潜行决策树

```
玩家进入新区域
    │
    ├─ 看到敌人视野锥 → 分析巡逻路径 → 选择时机/路线
    │   ├─ 路径安全 → 蹲伏通过
    │   ├─ 路径不安全 → 投掷石子引开 → 通过
    │   └─ 路径不可能 → 评估战斗成本
    │       ├─ 成本可接受（1个敌人/武器耐久充足）→ 战斗
    │       └─ 成本不可接受 → 等待/寻找替代路线
    │
    └─ 看不到敌人 → 投掷石子试探 → 听反应
        ├─ 无反应 → 安全通过
        ├─ 脚步声接近 → 警戒，寻找掩体
        └─ 直接看到敌人 → 重新评估
```

## 6. 经济与资源平衡

### 6.1 局内经济：背包管理

**背包容量**：`[PLACEHOLDER]` 12 格（与现有 LootServer.max_loot_slots 一致）

**物品占用空间**：

| 物品类型 | 占用格数 | 典型数量/局 | 可带出 |
|----------|----------|-------------|--------|
| 消耗品·绷带 | 1 | 2–4 | 是 |
| 消耗品·镇静剂 | 1 | 1–2 | 是 |
| 消耗品·咖啡 | 1 | 1–2 | 是 |
| 消耗品·胶带 | 1 | 1–2 | 是 |
| 投掷物·石子 | 1 (堆叠×3) | 3–6 | 否 |
| 投掷物·药瓶 | 1 (堆叠×2) | 2–3 | 否 |
| 关键道具·钥匙/门禁卡 | 1 | 1–3 | 是 |
| 武器·近战 | 2 | 0–1 | 是 |
| 叙事战利品 | 1 | 2–4 | 是 |
| 金币战利品 | 1 (堆叠×99) | 若干 | 是 |

**背包压力设计**：
- 进入阶段2时：空背包（12格），玩家需要快速填满空格
- 阶段3–4：背包逐渐填满，玩家面临取舍 —— 带消耗品还是带战利品？
- 撤离前：理想情况是背包满且均为高价值物品
- **关键决策点**：当你只有 2 格空位，面前有一把新武器（占2格）和一个叙事文件（占1格），你选哪个？

### 6.2 经济流速模型

```
                    局内产出渠道
                    ────────────
                    搜刮 → 消耗品
                    搜刮 → 武器
                    击杀 → 经验
                    解谜 → 特殊物品
                    文件 → 叙事进度
                    
                    局内消费渠道
                    ────────────
                    受伤 → 消耗 绷带
                    理智低 → 消耗 镇静剂
                    体力空 → 消耗 咖啡
                    耐久低 → 消耗 胶带
                    
                    跨局保留（仅撤离成功时）
                    ──────────────────────
                    未使用的消耗品 → 带入下一局
                    拾取的新武器 → 带入下一局
                    金币战利品 → 仓库升级资金
                    叙事战利品 → 收集进度
```

**经济平衡目标**：

| 阶段 | 预计物资产出 | 预计物资消耗 | 净余 | 背包占用 |
|------|-------------|-------------|------|----------|
| 阶段1（病房） | 绷带×1 | 0 | +1 | 10% |
| 阶段2（走廊） | 消耗品×4, 武器×1, 投掷物×3 | 消耗品×1–2 | +5–6 | 50–60% |
| 阶段3（Boss1） | Boss掉落×1 | 消耗品×2–3 | -1 | 60–70% |
| 阶段4（治疗区） | 消耗品×5, 武器×1, 弹药×10 | 消耗品×2–3 | +3–4 | 80–90% |
| 阶段5（行政） | 消耗品×3, 关键物品×1 | 消耗品×3–4 | -1 | 90–100% |
| 阶段6（终局） | Boss掉落×1 | 消耗品×3–5 | -3 | 满 |

> **经济核心假设** `[PLACEHOLDER]`：玩家的背包在撤离前应该接近满格（10–12格），且至少还有 1–2 个消耗品剩余。如果 playtest 发现玩家经常空背包撤离或经常满背包浪费物资，则需调整产出曲线。

### 6.3 跨局经济：仓库升级

> 复用现有 WarehouseUpgradeUI，新增潜行类升级项

| 升级项 | 费用（金币） | 效果 | 最大等级 |

## 9. 系统交互矩阵

| | 潜行 | 警戒 | 理智 | 战斗 | 搜刮 | 升级 | 撤离 |
|---|------|------|------|------|------|------|------|
| **潜行** | — | 潜行降低警戒积累 | 低理智幻觉干扰潜行判断 | 潜行>战斗（优先策略） | 潜行可安全搜刮 | 无直接关系 | 潜行减少撤离前压力 |
| **警戒** | 高警戒=更易被发现 | — | 无直接关系 | 高警戒=更多敌人参战 | 高警戒=搜刮风险更高 | 无直接关系 | 高警戒可能封锁撤离点 |
| **理智** | 幻觉使潜行更困难 | 无直接关系 | — | 无直接关系 | 低理智=更难判断物资真假 | 无直接关系 | 无直接关系 |
| **战斗** | 战斗是潜行失败的结果 | 战斗→警戒+15~25 | 低语者战斗→理智流失 | — | 战斗消耗搜刮到的消耗品 | 战斗→经验→升级 | 无直接关系 |
| **搜刮** | 潜行能力决定搜刮安全 | 搜刮区域决定风险 | 部分文件→理智-5 | 搜刮到的武器决定战斗力 | — | 物资→升级材料 | 搜刮到的物品决定撤离收益 |
| **升级** | 升级可提升潜行能力 | 升级不影响警戒 | 升级可提升理智抗性 | 升级直接提升战斗力 | 升级需要搜刮物资 | — | 升级让撤离更容易 |
| **撤离** | 可潜行到撤离点 | 警戒影响撤离可用性 | 无直接关系 | 必须活到撤离点 | 撤离成功=物资保留 | 无直接关系 | — |

**设计意图**（Intentional Interactions）：
1. 潜行-搜刮 正反馈：好的潜行 → 安全的搜刮 → 更多物资 → 更多升级 → 更好的潜行
2. 战斗-警戒 负反馈：战斗 → 警戒上升 → 更多敌人 → 更多战斗 → 警戒更快上升（螺旋式恶化）
3. 搜刮-理智 反直觉：收集真相文件 → 理智下降 → 更难的判断 → 需要消耗镇静剂（玩家被迫面对代价）

**可接受的意外交互**（Acceptable Emergence）：
- 玩家用投掷物引敌人到陷阱区域（虽无陷阱系统，但与解谜房间互动是被期待的）
- 低理智玩家在 Boss 战中看到额外幻觉敌人，增加压力（是设计预期内的）

**需要防范的滥用**（Bug if found）：
- 在安全屋门口反复进出刷警戒归零 ← 需加冷却
- 用投掷物把地图所有敌人引到一个角落然后从另一边跑 ← 设计上可接受，但需确保投掷物数量有限

## 10. Playtest 验证计划

### 10.1 第一次 Playtest 目标

**核心假设验证**：潜行是否真的比战斗更优先？

**成功指标**：
- [ ] 70% 以上的玩家在阶段 2 的首次遭遇中选择潜行绕过而非交战
- [ ] 玩家能够在不击杀任何巡逻员的情况下完成阶段 2
- [ ] 阶段 2 平均完成时间 > 3 分钟（太短说明走廊太简单）

**失败指标**：
- [ ] 超过 50% 的玩家选择战斗而非潜行
- [ ] 玩家抱怨"潜行太慢/不划算"
- [ ] 警戒值在阶段 2 的平均峰值 < 30（说明玩家压力不够）

### 10.2 第二次 Playtest 目标

**经济循环验证**：搜刮→背包管理→撤离是否有意义？

**成功指标**：
- [ ] 玩家在撤离前背包平均占用 80%（10/12 格）
- [ ] 至少出现 1 次"背包满了，需要做出取舍"的决策时刻
- [ ] 撤离成功时，玩家平均保留了 2+ 个消耗品

**失败指标**：
- [ ] 玩家经常带着半空背包撤离
- [ ] 没有出现背包取舍的决策时刻
- [ ] 消耗品太充裕，玩家不需要管理

### 10.3 第三次 Playtest 目标

**Boss 战体验验证**：Boss 战是否有趣且有叙事意义？

**成功指标**：
- [ ] Boss 战平均 TTK 在 60–120 秒范围内
- [ ] 玩家在 Boss 战中使用至少 1 个消耗品（说明有压力）
- [ ] 50% 以上玩家注意到 Boss 技能和叙事的关系

**失败指标**：
- [ ] Boss 战时间 > 180 秒（说明太磨叽）
- [ ] Boss 战时间 < 30 秒（说明太简单）
- [ ] 玩家反映"Boss 战和普通战斗没有区别"
