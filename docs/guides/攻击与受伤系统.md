# 攻击与受伤系统实现文档

## 一、系统概述

本项目的攻击与受伤系统采用**事件驱动 + 钩子扩展**的架构设计，核心分为两大模块：

| 模块 | 职责 | 核心文件 |
|------|------|----------|
| **攻击系统** | 处理玩家攻击行为，包括枪械射击和近战攻击 | `BaseGun.gd`、`BaseMeleeWeapon.gd`、`Bullet.gd` |
| **受伤系统** | 处理玩家和怪物的受伤逻辑 | `Hero.gd`、`BaseMonster.gd`、`PlayerData.gd` |

## 三、受伤系统实现

### 3.1 怪物受伤流程

```
受到攻击 → hitFlash() → onHit() → 伤害修正 → HP减少 → 死亡判定
```

**核心代码流程**：

1. **击中闪烁与击退** ([BaseMonster.gd 第77-94行](file:///d:/Projects/Godot/TowDownGame/game/monster/BaseMonster.gd#L77-L94))
   ```gdscript
   func hitFlash(collisionResult, bullet:Bullet):
       if is_die: return
       Utils.freezeFrame(bullet.gun.time_scale)
       onHit(bullet.hurt)
       audio_hit.play(0.17)
       var speed = bullet.knockback_speed - knockback_def
       if speed > 0:
           velocity = -(global_position.direction_to(Utils.player.global_position)) * speed
           hit = true
   ```

2. **伤害计算与奖励钩子** ([BaseMonster.gd 第97-116行](file:///d:/Projects/Godot/TowDownGame/game/monster/BaseMonster.gd#L97-L116))
   ```gdscript
   func onHit(hit_num, is_show_label = true, is_death_effect = true):
       # 暴击判定
       if PlayerData.base_aim_enh > 0 && PlayerData.base_aim_enh > randi()%100:
           hit_num *= 1.5
       
       # beforeAtk钩子：伤害修正
       var nodes = get_tree().get_nodes_in_group("reward")
       var temp_hurt = 0
       for node in nodes:
           if node.connect_beforeAtk:
               var num = node.call("beforeAtk", self, hit_num)
               temp_hurt += num
       hit_num += temp_hurt
       
       # HP减少
       if HP:
           HP -= hit_num
           if HP <= 0:
               onDie(is_death_effect)
       
       # afterAtk钩子：伤害后处理
       for node in nodes:
           if node.connect_afterAtk:
               node.call("afterAtk", self, hit_num)
   ```

3. **死亡处理** ([BaseMonster.gd 第118-136行](file:///d:/Projects/Godot/TowDownGame/game/monster/BaseMonster.gd#L118-L136))
   - 播放死亡动画

### 3.2 玩家受伤流程

```
受到攻击 → Hero.onHit() → 奖励钩子修正 → PlayerData.player_hp减少 → UI更新
```

**核心代码流程** ([Hero.gd 第170-188行](file:///d:/Projects/Godot/TowDownGame/game/hero/Hero.gd#L170-L188))：

```gdscript
func onHit(hurt):
    # beforePlayerHit钩子：伤害减免
    var nodes = get_tree().get_nodes_in_group("reward")
    var temp_hurt = 0
    for node in nodes:
        if node.connect_beforePlayerHit:
            var num = node.call("beforePlayerHit", hurt)
            temp_hurt += num
    hurt += temp_hurt
    
    # 最小伤害保护
    if hurt < 1:
        hurt = 1
    
    # 扣血
    PlayerData.player_hp -= hurt
    
    # 显示伤害数字
    Utils.showHitLabel(hurt, self)
    
    # UI反馈
    get_tree().call_group("control", "hit")
    Utils.freezeFrame(0.1)
    
    # afterPlayerHit钩子：受伤后处理
    for node in nodes:
        if node.connect_afterPlayerHit:
            node.call("afterPlayerHit", hurt)
```

## 四、伤害计算公式

### 4.1 枪械伤害
```
最终伤害 = 武器基础伤害 × (1 + 子弹伤害增幅) + 玩家基础伤害
```

### 4.2 近战伤害
```
最终伤害 = 武器基础伤害 × (1 + 玩家基础伤害)
```

### 4.3 暴击机制
```
暴击条件：PlayerData.base_aim_enh > 0 且 random(0-100) < base_aim_enh
暴击倍率：1.5倍
```

### 4.4 击退计算
```
击退速度 = 子弹击退速度 - 怪物击退抵抗
击退方向 = 怪物位置 → 玩家位置 的反方向
```

## 五、奖励系统钩子

### 5.1 钩子类型

| 钩子名称 | 触发时机 | 调用参数 | 作用 |
|----------|----------|----------|------|
| `connect_beforeAtk` | 怪物受伤前 | `(monster, hit_num)` | 伤害增加/减少 |
| `connect_afterAtk` | 怪物受伤后 | `(monster, hit_num)` | 伤害后处理 |
| `connect_kill` | 怪物死亡时 | `(monster)` | 击杀奖励 |
| `connect_beforePlayerHit` | 玩家受伤前 | `(hurt)` | 伤害减免 |
| `connect_afterPlayerHit` | 玩家受伤后 | `(hurt)` | 受伤后效果 |

### 5.2 钩子调用流程

```
伤害事件 → before钩子（可修改伤害）→ 实际扣血 → after钩子（副作用处理）
```

## 七、核心设计特点

### 7.1 模块化设计
- **攻击逻辑与受伤逻辑分离**：武器只负责生成攻击事件，不处理受伤逻辑
- **数据与表现分离**：`PlayerData` 管理玩家数据，`Hero`/`BaseMonster` 管理表现

### 7.2 可扩展性
- **钩子系统**：通过 `reward` 组节点实现无侵入式扩展
- **组件化武器**：枪械和近战武器都继承自基类，易于添加新武器类型

### 7.3 状态管理
- **死亡状态保护**：`is_die` 标志防止重复处理死亡逻辑
- **实例有效性检查**：使用 `is_instance_valid()` 避免空引用错误

### 7.4 用户反馈
- **帧冻结**：`Utils.freezeFrame()` 增强打击感
- **伤害数字**：`Utils.showHitLabel()` 显示伤害值
- **屏幕抖动**：`cameraSnake()` 提供视觉反馈
